# Lesson 001：终端与你的第一个 Python 程序

> 本节课学会三件事：**终端是什么、怎么用、怎么让 Python 运行你的第一个程序**。

---

## 1. 终端是什么？

终端（Terminal）是一个**用文字和电脑对话的窗口**。
你输入一行命令，按回车，电脑执行并显示结果。

类比：平时你用鼠标点图标（图形界面），终端就是直接打字下命令（命令行界面）。
两者都能操作电脑，但命令行更精确、更强大、更快——程序员天天用。

## 2. 在 VSCode 里打开终端

1. 打开 VSCode（如果没打开，就打开 `D:\a_deepseek_workshop\Coding` 这个文件夹）

**提示符里的 `>` 代表：电脑正等着你输入命令。**

## 3. 几个最常用的命令（先记住前两个）

| 命令 | 作用 | 例子 |
|------|------|------|
| `cd 文件夹名` | 进入文件夹 | `cd D:\a_deepseek_workshop\Coding` |
| `dir`（Windows）/ `ls` | 列出当前文件夹的内容 | `dir` |
| `python` | 启动 Python | `python` |
| `cls` | 清空终端 | `cls` |

> 小技巧：输入 `cd` 后按 Tab 键可以自动补全文件夹名。

## 4. Python 的两种运行方式

### 方式一：交互模式（临时聊天）

在终端输入 `python` 回车，会出现 `>>>`：

```
>>> print("hello")
hello
>>>
```

- `>>>` 表示 Python 在等你输入代码，输入一行它执行一行
- 输入 `exit()` 或按 Ctrl+Z 再回车，退出
- 适合快速试一句代码，不适合写长程序

### 方式二：脚本文件（正式写程序）

1. 在 VSCode 左侧文件区，右键 `PROJECTS` 文件夹 → 新建文件 → 命名 `hello.py`
2. 在文件里写：

```python
print("hello")
print("我是第一次写 Python 程序！")
```

3. 在终端输入 `python PROJECTS\hello.py` 回车
4. 你会看到两行输出

**区别**：交互模式是「一问一答」，脚本文件是「一次写好，反复运行」。

## 5. print 是什么？

`print(...)` 是 Python 内置的「喊话」函数：把括号里的内容显示到屏幕上。

- 字符串要用引号包起来：`print("你好")`
- 数字不用引号：`print(123)`
- 括号里可以放多个东西，用逗号分隔：`print("你好", 123)`

## 6. 练习（一定要动手做）

1. 写一个 `hello.py`，打印你的名字和一句自我介绍
2. 在交互模式里试试：`print(1 + 1)`、`print("A" * 10)`——先猜结果，再回车验证
3. 故意打错一个地方（比如把 `print` 写成 `prnit`），看终端报什么错

> **报错不可怕**——报错是程序在告诉你哪里不对，学会读报错是程序员的基本功。

## 7. 常见问题对照表

| 现象 | 原因 | 解决 |
|------|------|------|
| `'python' 不是内部或外部命令` | Python 没在 PATH 里 | 用 `py` 代替 `python` |
| 运行后什么都没发生 | 忘了写 print | 程序只算不喊话，当然没声音 |
| 提示找不到文件 | 当前目录不对 | 先 `cd` 到文件所在目录 |
| 中文显示乱码 | 编码问题 | 确认文件保存为 UTF-8（VSCode 默认就是） |

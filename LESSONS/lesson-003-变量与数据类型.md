## 1. 变量：给数据贴标签

**变量 = 一个贴了名字的盒子，里面装数据。**

```python
name = "小明"   # 盒子上贴 name，里面装 "小明"
age = 18        # 盒子上贴 age，里面装 18
```

- `=` 是**赋值**：把右边的东西装进左边的盒子（注意：不是数学里的"等于"）
- 盒子里可以随时换东西：`age = 19`（旧值 18 被覆盖）
- 用的时候直接用名字：`print(name)` 会显示 `小明`

**命名规则**（记 3 条就够）：
1. 只能由字母、数字、下划线 `_` 组成，**不能以数字开头**（`1name` 不行）
2. 不能是 Python 关键字（如 `if`、`for`、`class`）
3. 区分大小写：`Name` 和 `name` 是两个不同的变量

> 约定俗成：变量名用小写字母 + 下划线，如 `user_name`、`total_price`。

## 2. 四种基本数据类型

| 类型 | 英文 | 例子 | 说明 |
|------|------|------|------|
| 整数 | int | `18`、`-3`、`0` | 没有小数点的数字 |
| 浮点数 | float | `3.14`、`0.5` | 带小数点的数字 |
| 字符串 | str | `"hello"`、`'你好'` | 文本，**必须用引号包起来** |
| 布尔 | bool | `True` / `False` | 只有这两个值，表示真/假 |

**怎么知道一个变量是什么类型？用 `type()`：**

```python
print(type(18))      # <class 'int'>
print(type(3.14))    # <class 'float'>
print(type("hello")) # <class 'str'>
print(type(True))    # <class 'bool'>
```

> 关键区别：`18` 是数字，`"18"` 是字符串——长得一样，但一个是数、一个是文本。

## 3. 数字运算

| 运算符 | 意思 | 例子 | 结果 |
|--------|------|------|------|
| `+` `-` `*` | 加减乘 | `7 + 3` | `10` |
| `/` | 除法（结果是浮点数） | `10 / 3` | `3.333...` |
| `//` | 整除（只留整数部分） | `10 // 3` | `3` |
| `%` | 取余 | `10 % 3` | `1` |
| `**` | 幂 | `2 ** 3` | `8` |

> 新手最容易踩的坑：`10 / 3` 结果是 `3.333...` 而不是 `3`。
> 想要整数结果，用 `//`（整除）。

## 4. 字符串基础

```python
first = "张"
last = "三"
full = first + last        # 拼接：用 +
print(full)                # 张三
print("哈" * 3)            # 哈哈哈哈哈哈 哈？不对——是 "哈哈哈"（字符串也能乘！）

name = "小明"
age = 18
print(f"我叫{name}，今年{age}岁")   # f-string：f 开头，{变量} 直接往里放
print(len("hello"))                # 5（len() 求长度）
```

**f-string 是字符串里最重要的技能**，以后写代码天天用：`f"..."` 里面用 `{变量名}` 插值。

## 5. 从键盘输入：input()

```python
name = input("请输入你的名字：")   # 程序停下来等用户输入，回车后存进 name
print(f"你好，{name}！")
```

两个重点：
1. `input()` 返回的**永远是字符串**（就算你输入的是 123，也是 `"123"`）
2. 要当数字用，必须转换：`age = int(input("年龄："))`（`int()` 把字符串变整数，`float()` 变浮点数）

## 7. 常见错误对照表

| 报错 | 原因 | 解决 |
|------|------|------|
| `NameError: name 'x' is not defined` | 变量没定义或拼写错了 | 检查名字拼写 |
| `TypeError: can only concatenate str...` | 字符串和数字混着用 `+` | 用 f-string 或 `str()` 转换 |
| `SyntaxError` | 语法错误（引号没配对、括号没闭合） | 看报错提示的行号，检查那行 |
| `ValueError: invalid literal for int()` | `int()` 转换了不能转的内容 | 确认输入的是纯数字 |

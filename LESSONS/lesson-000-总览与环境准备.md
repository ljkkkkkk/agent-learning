## 1. 我们要学什么

**最终目标**：从零基础 → 能独立开发 AI Agent → 能面试「Agent 开发」岗位。

学习内容分三大块：

1. **Python 编程**——Agent 主要用 Python 写，这是地基

前端技术只会用到一点点（做项目 2 时），到时候老师会详细解释，现在完全不用管。

**为什么是这个顺序？**
先学会写代码 → 再学会调大模型 → 然后理解 Agent 的原理 → 最后做出自己的 Agent。
就像盖房子：地基（Python）→ 框架（API）→ 装修（Agent 循环）→ 入住（项目）。

## 4. 三个重要的「是什么」

### Git 是什么？
一个**版本管理工具**。它记录你每次修改代码的快照（叫 commit），可以随时回退、对比、协作。
想象成：写作文时的「另存为 v1、v2、v3...」，但 Git 是自动、高效、能分叉合并的版本。

### GitHub 是什么？
一个**存放代码的网站**（托管服务）。本地 Git 仓库可以推送到 GitHub，
别人能看到、能协作，也是求职时展示项目的地方。你的仓库：https://github.com/ljkkkkkk/agent-learning

### VSCode 是什么？
一个**写代码的编辑器**。有语法高亮、自动补全、集成终端，是目前最流行的 Python 编辑器。

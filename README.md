# agent-learning 学习仓库

> 本仓库用于从零开始学习编程（Python）与 AI Agent 开发，目标是达到能够面试「Agent 开发工程师」岗位的水平。
> GitHub 仓库地址：https://github.com/ljkkkkkk/agent-learning

## 这个仓库是干什么的

- 存放**课程讲义**（`LESSONS/`）
- 存放**每次对话的日志**（`LOGS/`）——即使换聊天窗口，也能从这里接上进度
- 存放**学习路线与进度追踪**（`ROADMAP.md` / `PROGRESS.md`）
- 存放**练习与项目代码**（`PROJECTS/`）
- 存放**自己的笔记**（`NOTES/`）

## 目录结构

| 路径 | 作用 |
|------|------|
| `README.md` | 本文件：总入口，先读这个 |
| `CHEATSHEET.md` | 命令速查表（终端 + git + python 已学内容，忘了就翻它） |
| `ROADMAP.md` | 完整学习路线图（7 个阶段，约 6 个月） |
| `PROGRESS.md` | 当前进度：学到哪了、下次学什么 |
| `LESSONS/` | 课程讲义，按编号排列（lesson-000 开始） |
| `LOGS/` | 每次对话的日志，从 session-001 开始 |
| `NOTES/` | 你自己做的笔记（强烈建议做） |
| `PROJECTS/` | 练习和项目代码，一个项目一个子文件夹 |

## 快速开始

1. 先读 `ROADMAP.md` 了解全貌
2. 读 `LESSONS/lesson-000-总览与环境准备.md` 了解环境与工具
3. 跟着 `PROGRESS.md` 的「下一步」走

## 学习规则（师生约定）

- 每次对话结束，老师（AI）会更新 `LOGS/` 和 `PROGRESS.md`，保证进度不丢
- 新文件必须分类放入对应目录，不允许乱放
- 学到的知识点尽量自己动手写一遍，再让 AI 检查
- 遇到不懂的随时问，但先自己想一想（想 5 分钟再问，记得更牢）
